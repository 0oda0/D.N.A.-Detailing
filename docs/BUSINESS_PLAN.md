# D.N.A. Detailing — как должен работать сайт (бизнес-модель)

## 1. Задача сайта
Сайт — не визитка, а **рабочий инструмент**, который:
1. Превращает посетителя в запись (онлайн, Telegram, звонок, заявка «перезвоните»).
2. Заполняет расписание без накладок — клиент видит только реально свободное время.
3. Даёт владельцу цифры: выручка, загрузка, средний чек, что продаётся, кто работает.

## 2. Воронка клиента
| Этап | Где происходит | Что меряем (вкладка «Отчёты») |
|---|---|---|
| Узнал | Яндекс Карты, 2ГИС, Авито, Telegram-канал, сарафан | — (позже: метрика) |
| Зашёл на сайт | Главная: оффер, цены «от», калькулятор | Яндекс Метрика |
| Оставил контакт | Онлайн-запись / заявка на звонок / Telegram | Заказы, заявки |
| Пришёл | Статус «Подтверждён» → «В работе» | Отмены, % отмен |
| Оплатил | Статус «Готово», админ правит **итоговую сумму** | Выручка, средний чек |
| Вернулся | Повторный заказ с того же телефона | % повторных клиентов |

## 3. Роли и ежедневный регламент
- **Клиент** — записывается сам, видит свои заказы, может отменить.
- **Мастер** — утром открывает «Работы», берёт заказы, жмёт «Начать» / «Готово».
- **Админ (Даниил / Никита)**:
  - каждые 1–2 часа: новые заказы → подтвердить (позвонить/написать), заявки на звонок → перезвонить ≤ 15 мин;
  - после работы: проставить **реальную сумму** и «Готово» — иначе отчёты врут;
  - раз в неделю: «Отчёты» → загрузка по дням недели, топ услуг, средний чек;
  - раз в месяц: выгрузка CSV для бухгалтерии.

## 4. Ключевые показатели (что считать нормой)
| Показатель | Цель на старте | Что делать, если ниже |
|---|---|---|
| Загрузка | 50–70 % | акции на «пустые» дни недели, реклама на Авито/Картах |
| Отмены | < 15 % | подтверждать запись за день, напоминание в Telegram |
| Средний чек | растёт | допродажа: керамика после полировки, антидождь к любой мойке |
| Повторные клиенты | > 25 % | абонемент/скидка на 2-й визит, напоминание через 3–6 мес. |

## 5. Ценообразование
Сейчас цены «от». Следующий шаг — **цена по классу авто**: в справочнике cars-base у каждой модели есть класс
(A/B — малый, C — гольф-класс, D/E — средний/бизнес, F — представительский, J — внедорожник, M — минивэн, S — спорткар). Можно задать коэффициенты
(например ×1.0 / ×1.2 / ×1.4) и показывать в калькуляторе точную цену для выбранной машины.

## 6. Что уже сделано на сайте
- Лендинг: оффер, преимущества, цены, калькулятор, этапы, FAQ, заявка на звонок, плавающие кнопки, контакты.
- Онлайн-запись на свободное время с учётом длительности работ и числа боксов.

- Маски: телефон `+7 (XXX) XXX-XX-XX`, госномер `А 123 ВС 777` (латиница → кириллица автоматически).
- Кабинеты клиента, мастера, админа; заявки; управление услугами, ролями, расписанием.
- Отчёты с графиками и выгрузкой заказов в Excel (CSV).

## 7. Что улучшить дальше (по приоритету)
1. **Уведомления в Telegram** админу о новой записи/заявке (бот, ~1 час работы) — самое важное, чтобы не терять клиентов.
2. **Напоминание клиенту** за день до визита (Telegram/SMS) — снижает отмены.
3. **Галерея «до/после» и отзывы** — нужны реальные фото и отзывы (можно из канала).
4. **Домен + HTTPS** (`dna-detailing.ru`, ~200 ₽/год) и **Яндекс Метрика** — для доверия, SEO и учёта рекламы.
5. ~~Цена по классу авто~~ — сделано: Админка → «Цены по авто» (множители по типу кузова и классу).
6. **Расходы** (химия, зарплаты, аренда) в админке → отчёт о прибыли, а не только выручке.
7. Карточка в **Яндекс Бизнес / 2ГИС** со ссылкой на онлайн-запись.
8. Политика обработки персональных данных (152-ФЗ) — отдельная страница.
