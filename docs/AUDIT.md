## Остаётся — требует решения владельца
### Критично
1. **Сайт работает по HTTP.** Пароли и данные идут по сети открытым текстом (опасно в публичном Wi-Fi). Нужен домен + HTTPS (Let's Encrypt). После — `COOKIE_SECURE=1`.
2. **152-ФЗ.** Сайт собирает ФИО, телефоны, госномера → нужна политика обработки ПДн, согласие (галочка) и уведомление Роскомнадзора. Данные граждан РФ должны храниться на сервере в РФ (242-ФЗ) — проверьте, где физически VPS.
3. **Пароль root был отправлен в чат** — сменить (`passwd`), лучше перейти на вход по SSH-ключу и отключить пароль.

### Бизнес-логика
4. **Запись только после регистрации** — главный «отвал» воронки. Вектор: запись гостем (имя + телефон), аккаунт создаётся по желанию.
5. **Нет подтверждения телефона (SMS / Telegram-звонок).** Из-за этого все привязки идут через админа. С подтверждением — привязка автоматическая и безопасная.
6. **Выездные работы занимают бокс.** Химчистка мебели «на выезде» сейчас съедает слот в сервисе. Нужен флаг «выездная услуга»: отдельная ёмкость (мастер, а не бокс) + адрес клиента.
7. **Работы длиннее рабочего дня** (плёнка + шумоизоляция) онлайн не записать. Вектор: многодневная запись (авто остаётся на ночь).
8. **Нет предоплаты/депозита** на дорогие работы → риск неявки на 8-часовой слот. Вектор: предоплата через ЮKassa/СБП для услуг дороже N ₽.
9. **Нет правила отмены.** Клиент может отменить за 5 минут до визита. Вектор: отмена онлайн не позднее чем за X часов, дальше — только звонком.
10. **Мастера без графика.** Свободное время считается по боксам, не по людям: если мастер в отпуске, окна всё равно «свободны». Вектор: график мастеров и привязка услуг к компетенциям.
11. **Цена «от» vs итог.** Итог правится вручную; нет скидок/промокодов/абонементов, нет причины изменения суммы. Вектор: скидка %/₽ с комментарием, промокоды, карта лояльности (каждый 5-й визит).
12. **Выручка = сумма по дате визита**, нет оплат (нал/карта/перевод), нет кассы (54-ФЗ). Вектор: учёт оплат и способов, интеграция онлайн-кассы, расходы → прибыль.
13. **Удаление заказа безвозвратно** и без журнала. Вектор: «корзина» и журнал действий (кто что поменял) — защита от злоупотреблений сотрудников.
14. **Заявки на звонок** без статуса «перезвонили / не дозвонились / записан» и без конверсии в заказ. Вектор: мини-CRM по заявкам.
15. **Повторные продажи.** Есть гараж и история — можно напоминать «керамике 6 месяцев, пора обновить», «через год — повторная полировка». Это самый дешёвый канал выручки.

### Техника
16. Нет мониторинга доступности и логов ошибок (узнаете о падении от клиента). Вектор: UptimeRobot (бесплатно) + алерт в Telegram.
17. Каталог авто (`cars.json`, ~170 КБ) отдаётся без сжатия — добавить gzip через nginx вместе с HTTPS.
18. Одна база SQLite — для одного центра достаточно; при сети филиалов — PostgreSQL.

## Презентация — что поправлено
- «Пароли в зашифрованном виде» → «в виде необратимого хэша» (зашифрованное можно расшифровать, хэш — нет).
- Слайд «Технологии»: упомянут автоматический ежедневный бэкап.
- Заметки к слайду «Гараж»: привязка по телефону теперь тоже через подтверждение админом.
