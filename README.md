# D.N.A. Detailing — сайт-визитка с онлайн-записью

- **Визитка** со списком услуг, телефоном и баннером «Выездные работы».
- **Онлайн-запись** — клиент выбирает услуги, указывает авто и дату; показываются только **свободные** окна с учётом суммарной длительности работ и числа боксов. Двойная запись на одно время исключена (проверка в транзакции).
- **Роли**: клиент (регистрация по телефону), мастер (регистрация с кодом сотрудника или повышение админом), админ.
- **Мастер**: список работ на период, «Взять», «Начать», «Готово».
- **Админ**: все заказы (статус, мастер, перенос, удаление), создание заказа за клиента (зарегистрированного или нового по имени/телефону), услуги (добавить/изменить/скрыть, длительность в минутах, цена), пользователи и роли, настройки (часы работы, шаг сетки, кол-во боксов, выходные, адрес, телефон).

Стек: Node.js 22 + Express + встроенный SQLite (`data/dna.sqlite`). Никаких внешних БД.

## Запуск локально
```bash
npm install && npm start   # http://localhost:3000, админ +79686107799 / admin12345
```

## Установка на сервер (Ubuntu/Debian, без домена)
```bash
ssh root@IP_СЕРВЕРА
apt-get update && apt-get install -y git
git clone https://github.com/0oda0/D.N.A.-Detailing.git /root/dna && cd /root/dna
git checkout claude/funny-wozniak-ddj9ky
bash deploy/install.sh
```
Скрипт ставит Node.js 22, systemd-сервис `dna-detailing` на порт 80 и печатает пароль админа и код сотрудника (лежат в `/opt/dna-detailing/.env`).
Сайт будет доступен по `http://IP_СЕРВЕРА/`.

Обновление: `cd /root/dna && git pull && bash deploy/install.sh`.
Логи: `journalctl -u dna-detailing -f`. Бэкап: скопировать `/opt/dna-detailing/data/`.

Если репозиторий приватный — `git clone` попросит GitHub-токен, либо скопируйте папку: `scp -r . root@IP:/root/dna`.

Когда появится домен: поставить nginx + certbot перед приложением (PORT=3000 в `.env`) и добавить `COOKIE_SECURE=1`.

## Telegram-бот (напоминания клиентам и уведомления админу)
1. В Telegram откройте @BotFather → `/newbot` → придумайте имя → получите токен.
2. На сервере:
   ```bash
   echo "TELEGRAM_BOT_TOKEN=ВАШ_ТОКЕН" >> /opt/dna-detailing/.env
   echo "SITE_URL=http://155.212.173.37:8080" >> /opt/dna-detailing/.env
   systemctl restart dna-detailing
   ```
3. Админ: «Админка → Настройки → Подключить Telegram» — сюда приходят новые записи, заявки, отмены, отзывы.
4. Клиент: «Мои заказы → Подключить Telegram» — напоминание за сутки до визита, «запись подтверждена», «авто готово».

Фото работ хранятся в `/opt/dna-detailing/data/uploads/` — включайте эту папку в бэкап.
