# Studio Booking — white-label сайт с онлайн-записью и CRM

Готовый проект для сервисного бизнеса (детейлинг, автосервис, шиномонтаж, химчистка и т.п.), который
**перекрашивается под любую компанию из админки** — без правки кода.

👉 **Презентация всех экранов и бизнес-логики:** откройте `/showcase/` на запущенном сайте (файл `public/showcase/index.html`).

## Что внутри
- **Сайт-лендинг:** оффер, услуги и цены, калькулятор, галерея «до/после», отзывы, FAQ, заявка на звонок.
- **Онлайн-запись** только на свободное время (длительность работ × боксы × мастера на смене), **без регистрации** или из кабинета.
- **Кабинеты:** клиент (заказы, профиль, гараж авто), мастер (работы на смену), администратор (CRM).
- **CRM:** ручные заказы, оплаты и предоплаты, скидки и промокоды, расходы и прибыль, отчёты с графиками,
  повторные продажи, график мастеров, журнал действий и корзина, Telegram-бот.

## Перенастройка под компанию (5 минут)
**Админка → Настройки → 🎨 Бренд:** название, подпись, слоган, тексты главной, фирменный цвет, Telegram-контакты и канал.
Дальше: **Услуги** (цены, длительность, выезд, сроки повторов), **Цены по авто** (множители), **Настройки** (часы, боксы, предоплата, отмена).

## Запуск локально
```bash
npm install && npm start   # http://localhost:3000, админ +79990000000 / admin12345
```
Демо-данные для показа клиенту: `node scripts/demo-seed.js` (на пустой базе).

## Установка на сервер (Ubuntu/Debian)
```bash
git clone <URL-репозитория> /root/site && cd /root/site
ADMIN_PHONE=+7XXXXXXXXXX PORT=80 bash deploy/install.sh
```
Скрипт ставит Node.js 22, systemd-сервис `studio-site`, ежедневный бэкап (`/var/backups/studio`) и печатает пароль админа и код сотрудника
(они же в `/opt/studio-site/.env`). Обновление: `git pull && bash deploy/install.sh`. Логи: `journalctl -u studio-site -f`.

### Telegram-бот
@BotFather → `/newbot` → токен, затем:
```bash
echo "TELEGRAM_BOT_TOKEN=ТОКЕН" >> /opt/studio-site/.env
echo "SITE_URL=https://ваш-домен" >> /opt/studio-site/.env
systemctl restart studio-site
```
Админ подключает уведомления в Настройках, клиент — в профиле.

### Домен и HTTPS
Поставьте nginx + certbot перед приложением (`PORT=3000` в `.env`) и добавьте `COOKIE_SECURE=1`.

Стек: Node.js 22, Express, встроенный SQLite. Документы: `docs/BUSINESS_PLAN.md`, `docs/AUDIT.md`.
